    ANOTHER PYTHON HELPER

    How Flask works

    Flask helps a web page talk to a Python program. It listens for a message, finds the matching Python function, then sends the answer back.

    1. 1The page asksGET /tasks means "show me the tasks."
    2. 2Flask finds the right jobIt runs the function marked with @app.get("/tasks").
    3. 3The function answersjsonify packs Python data so the page can read it.

    This Taskroom uses FastAPI instead. Flask and FastAPI are different tools that can do similar jobs.

    A TINY FLASK EXAMPLE

    from flask import Flask, jsonify

app = Flask(__name__)

@app.get("/tasks")
def show_tasks():
    return jsonify({"task": "Read a book"})

    When the page asks for /tasks, Flask runs show_tasks.

    THE APP'S LUNCHBOX

    How Docker runs this page

    Docker packs the app so it can run the same way on different computers. Here is what each Docker word means:

    1. 1Dockerfile = recipeIt tells Docker what to put together.
    2. 2Image = packed appThe image is named taskroom.
    3. 3Container = app running nowThis container is named taskroom-demo.
    4. 4Ports = two doorsYour browser uses 8001; Docker sends it to the app's 8000.

    Docker Desktop shows the same container under Containers. Click its name to see its logs.

    CHECK WHAT IS HAPPENING

    docker ps
docker logs taskroom-demo
docker stop taskroom-demo

    docker ps shows what is running. docker logs shows its messages. docker stop stops it.

    START THIS APP AGAIN

    docker run --rm -d --name taskroom-demo -p 8001:8000 taskroom

    If you change the app, first rebuild it with docker build -t taskroom ..
